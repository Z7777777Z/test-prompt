计费口径：按模型自身的输入/输出计费单位折算（K=1000 / 万=10000 / 十万=100000 / 百万=1000000），金额保留 4 位小数。 「调试」为真实调用所选模型。 「评估」用选定评估对象模型的模型、api_key、系统提示词对每条问题真实对话，回答写入「大模型结果」列， token 与费用以接口返回的真实 usage 为准（判定模型的用量不计入本页金额）。 「判定结果」由独立的判定模型（配置见 config/judge_config.json）判定「标准答案」与「模型答案」是否一致 （文本含义一致 / 代码功能等价即判正确），也可下拉人工纠正，正确/错误/准确率等指标随之实时变化。 「导入数据」支持 .xlsx / .csv 的「问题 + 标准答案」两列（表头可选），导入后点「评估」逐条真实调试、自动判定并写入评估表； 「导出 Excel」输出带 BOM 的 CSV（Excel 可直接打开）。 「保存」先弹出「模块名称」确认框，确定后写入数据库 Prompt_Test_DB 的 prompt 表，并跳转到「提示词 / 调试列表」。
